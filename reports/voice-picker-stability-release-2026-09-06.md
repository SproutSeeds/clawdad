# Voice picker stability repair

iPhone build 47 is VALID and IN_BETA_TESTING in the existing ClawDad Internal
TestFlight group. The Mac patch is built as 0.7.0 build 56, signed, notarized,
stapled, and ready to install. Installation remains blocked by macOS denying

## Audit and behavior

Background voice replies replaced the desktop browsing draft and reset both
filters. Rendering could also change a focused native select's value before
the browser committed the selection. The iPhone form observed the entire live
CloudSession, and catalog replies reset its local selection and filters.

The repair keeps saved preferences separate from the current browsing draft.
Catalog updates and delayed save replies preserve the user's voice, language,
voice type, and speed. An explicit model change still selects that model's most
recent saved preference and resets its filters.

On iPhone, Voice opens a scrollable list within Settings. The list captures its
options when opened, uses stable row identifiers, and keeps its position while
session and catalog updates arrive. Selecting a voice returns to Preview and
Save; Back leaves the selection unchanged. Other selectors are isolated from
unrelated session updates with Equatable views. A Settings visit requests the
catalog once per paired computer, avoiding an extra request when returning from
the voice list. Duplicate catalogs are not republished.

On desktop, rendering preserves the options and value of a focused voice
selector and defers rebuilding nearby Settings controls until blur. Existing
populated selectors remain usable while a request is pending. Preview and Save
still wait for the request to finish.

Model inventory and synthesis behavior remain unchanged: Kokoro 54 voices,
Pocket 26 voices, and Kitten 8 voices. Speech remains generated by the existing
local Mac service. This patch adds no cloud storage or compute.
