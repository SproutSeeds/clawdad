# Saved Terminal setups

On the Mac’s main ClawDad screen, use **Terminal Setups**, above the project and message composer. The Mac and iPhone use the same local saved library on the paired Mac.

## Save a window

1. Click **Save Terminal Setup…**.
2. Choose the exact Terminal window. The list shows its ordered tabs; **Refresh Terminal windows** updates this preliminary list.
3. Enter a setup name and click **Save setup**.
4. A spinner and **Saving tab X of Y…** show the single inspection pass. ClawDad verifies project identities and recoverable drafts, returns to the previous tab, and saves the setup. **View saved setup** shows its exact conversations, directories and draft limitations afterward.

Let the inspection finish; manual Terminal activity can stop it safely. Closing this panel keeps the accepted save running. Reopen it to check the same request without starting another capture.

Different names can represent different windows or arrangements. Save does not close the window. A fresh Codex tab without a persisted conversation ID, an uncertain exited agent, or another unverifiable identity can prevent Save; the previous setup stays intact. Complete the intended startup/work or resolve the displayed issue, then save again.

To replace a saved lineup, open **Open Saved Setup…**, choose it, expand **Update or recover this setup**, and use **Update from a Terminal window…**. Choose its exact current window and confirm **Update setup**. This also uses a single capture pass. Absent tabs are removed from that saved version; its previous version remains recoverable. Background observations and closing tabs never rewrite a manual snapshot.

## Reopen a setup

1. Click **Open Saved Setup…** and choose a named setup.
2. Review its capture time, saved tabs, directories, conversation IDs and draft warnings.
3. Click **Open / Restore this setup**. Existing exact live conversations are reused. Confirmed missing conversations resume their saved IDs with their latest persisted history.

If another device updated the setup, click **Review latest saved version** before restoring. Where another window needs an explicit choice, **Other restore options** lets you add missing tabs to a chosen window or allow a separate window. Current tabs and drafts remain intact. Already-running conversations cannot be duplicated into another window.

The restored Terminal window fills the display’s usable area, keeping the menu bar and Dock available. Restore does not submit “continue,” replay tasks or native queues, or enable supervisors. Conversation history survives independently; an in-memory computation does not resume merely because its conversation ID was saved.

Missing drives, directories, history, permissions or competing owners appear as per-tab recovery information. Accepted progress and request IDs survive closing this panel; use **Check this request** to reconcile uncertain delivery. Opaque drafts and attachments cannot be reconstructed from a collapsed label. Read the saved limitations and preserve their originals before closing anything.

**Done** or Escape closes the desktop panel and restores keyboard focus. Whole-window closing remains a separate, explicitly confirmed action in the existing Terminal picker workflow.
