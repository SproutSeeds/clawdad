# ClawDad 0.7 Native Beta 19

The Apple-silicon and Intel downloads contain the same Mac build 41 product
surface. The matching private iPhone companion is `0.7.0 (34)`. This release
restores real Codex transcripts that were incorrectly superseded by empty local
threads, keeps recent threads ordered by actual conversation activity, makes
project loading explicit, and keeps the Remote Assist paste control available.

## Included

- Detects a quarantined Codex session when its real transcript is present again
  in the current Codex home.
- Restores that real session, rewires stale selectors to it, and retires the
  empty replacement without deleting transcript data.
- Prevents test or diagnostic runtimes using a temporary Codex home from
  mutating the normal ClawDad registry unless both homes are explicitly paired.
- Isolates the Codex integration server test from the live ClawDad home.
- Ranks all-project recent threads by provider activity, response time, and
  dispatch time, so merely opening a thread cannot move it to the top.
- Delivers the cached project catalog immediately, then refreshes the selected
  project in the background.
- Shows a clear loading indicator in the iPhone project picker while its live
  project list is arriving.
- Removes the duplicate empty-thread status message.
- Replaces the conditional iOS paste provider with an always-visible Remote
  Assist paste button that reads the iPhone clipboard only after a tap.
- Carries forward multi-computer routing, Mac-to-Mac pairing, multi-display
  Remote Assist, Terminal Tabs, Read Aloud, speech-to-text, image attachments,
  directory creation, model/reasoning controls, and special commands.

## Distribution Boundary

This native beta publishes signed Mac installers through
`https://clawdad.earth/` and the public `v0.7.0-beta.19` GitHub release. iPhone
build 34 is assigned only to the internal TestFlight group. The public npm CLI,
external TestFlight, Beta App Review, public App Store release, and the
separately controlled automatic-update feeds remain unchanged.

## Acceptance

1. Install the architecture-matched Mac build 41 and confirm the embedded
   runtime reports `0.7.0-beta.19`.
2. Open the previously empty `...9F475` selector and confirm it resolves to the
   restored Codex transcript with its conversation visible.
3. Open Projects on the iPhone during a refresh and confirm the loading state
   remains visible until the live list arrives.
4. Send or receive a message in a thread and confirm it moves to the top of
   Recent across all projects; simply viewing a thread must not reorder it.
5. Open an empty thread and confirm its empty-state text appears once.
6. Open Remote Assist and confirm Paste remains visible, reports an empty
   clipboard clearly, and pastes copied iPhone text after one tap.
