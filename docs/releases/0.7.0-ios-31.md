# ClawDad iPhone 0.7.0 Build 31

ClawDad iPhone build 31 adds multi-display Remote Assist and completes the
private native-host consolidation with ClawDad Mac `0.7.0 (26)`.

## Included

- Adds a Screens page to the compact Remote Assist menu when the paired Mac
  reports more than one display.
- Shows the active display, blocks remote input during a switch, and reconciles
  delayed or failed host replies without leaving the viewport stuck.
- Resets viewport zoom and aspect handling after a successful display change.
- Preserves compatibility with older single-display hosts that do not advertise
  display selection.
- Adds CMD+T to Special Commands.
- Adds a clipboard-safe Cut action to the message composer.
- Uses the paired Mac's bundled private runtime for shared Terminal and phone
  thread delivery.

## Distribution Boundary

Build 31 is limited to the private `ClawDad Internal` TestFlight group. The
external founding-customer group, public TestFlight link, Beta App Review, and
App Store submission remain unassigned.
