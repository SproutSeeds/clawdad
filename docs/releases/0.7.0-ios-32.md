# ClawDad iPhone 0.7.0 Build 32

ClawDad iPhone build 32 adds the Terminal tab switcher requested for Remote
Assist and pairs with ClawDad Mac `0.7.0 (28)`.

## Included

- Adds a Terminal icon to the compact `...` Remote Assist controls.
- Opens a focused Terminal Tabs panel with explicit Back and Refresh controls.
- Lists every open Terminal window/tab reported by the paired Mac, including
  its current and busy states.
- Focuses the selected Terminal window/tab and confirms the result without
  closing the Remote Assist controls.
- Handles loading, timeout, stale-catalog, locked-Mac, unavailable-tab, and
  Automation-permission states without trapping the user in the panel.
- Keeps the existing Screens selector as its own display-selection control.

## Distribution Boundary

Build 32 is limited to the private `ClawDad Internal` TestFlight group. The
external founding-customer group, public TestFlight link, Beta App Review, and
App Store submission remain unchanged.

## Physical Acceptance

- Install Mac build 28 and TestFlight build 32.
- Open Remote Assist, expand `...`, and tap the Terminal icon.
- Approve ClawDad's Terminal Automation request on the Mac if macOS asks.
- Choose at least two Terminal rows and confirm each exact window/tab is focused.
- Verify Back, Refresh, reconnect, Screens, keyboard, and clipboard controls.
