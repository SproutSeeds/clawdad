# ClawDad Mac 0.7.0 Build 30

ClawDad Mac build 30 explicitly registers and requests Terminal Automation
consent for Remote Assist.

## Included

- Uses macOS's dedicated Automation-consent API before reading or focusing a
  Terminal tab.
- Prompts securely for **ClawDad → Terminal** access when macOS has not recorded
  a decision yet.
- Opens Privacy & Security > Automation after a denied decision so the exact
  ClawDad permission can be changed without searching through Settings.
- Keeps Terminal Tabs open on the iPhone with a clear Refresh path after the
  user grants access.
- Carries forward the private Terminal tab switcher and multi-display Remote
  Assist used by iPhone TestFlight build 32.

## Distribution Boundary

Build 30 is a private signed and notarized native Mac release. The iPhone stays
on private internal TestFlight build 32. The public npm package, git tags,
GitHub release assets, public Sparkle appcast, external TestFlight group, Beta
App Review, and App Store submission remain unchanged.

## Physical Acceptance

- Keep iPhone TestFlight build 32 installed.
- Open Remote Assist, expand `...`, tap the Terminal icon, and tap Refresh.
- Confirm macOS presents a dialog naming ClawDad and Terminal.
- Choose Allow, then confirm ClawDad appears as a top-level Automation entry
  with Terminal enabled underneath it.
- Select a Terminal row and confirm its exact window and tab comes forward.
