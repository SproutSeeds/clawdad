# ClawDad 0.7 Native Beta 17

The Apple-silicon and Intel downloads contain the same Mac build 39 product
surface. This release completes shared Codex compatibility for both full-turn
and summary-only app-server histories, keeps native host upgrades on one clean
runtime, and carries forward the Mac composer and branding parity work. The
matching private iPhone companion remains `0.7.0 (33)`.

## Included

- Falls back to a supported summary-only thread read when the current Codex app
  server reports that `list_turns` is unavailable.
- Uses live completion events and accumulated response text for the owned turn
  when persisted turn history cannot be listed.
- Waits for a summary-only thread to become idle before starting a message when
  an active turn cannot be identified safely.
- Detects a poisoned shared Codex app-server socket that accepts local
  connections but cannot complete the WebSocket initialize handshake.
- Safely replaces that listener only after verifying its socket inode, current
  user, process command, and executable identity.
- Keeps startup ownership and runtime metadata isolated per socket so test or
  secondary runtimes cannot overwrite the production host record.
- Finds verified ClawDad server and cloud-host workers left parentless by an
  interrupted app replacement and stops them before starting the new runtime.
- Re-verifies the current user, parent state, PID, complete command, runtime
  paths, and managed port before signaling any leftover worker.
- Waits for ClawDad-owned child processes to exit during ordinary app shutdown,
  with a bounded forced-stop fallback.
- Adds the live Codex model catalog and each model's supported reasoning levels
  to the Mac composer tools.
- Persists the selected model and reasoning level and forwards both values when
  creating or continuing a Codex thread.
- Uses the iPhone app's ClawDad wordmark, baby-crawfish mascot, and catchphrase
  in the Mac app.
- Carries forward the bundled Node and ORP runtime, multi-computer routing,
  Mac-to-Mac pairing, multi-display Remote Assist, Terminal Tabs, Read Aloud,
  speech-to-text, image attachments, directory creation, clipboard controls,
  and special commands.

## Distribution Boundary

This native beta publishes the signed Mac installers through
`https://clawdad.earth/` and the public `v0.7.0-beta.17` GitHub release. iPhone
build 33 remains assigned only to the internal TestFlight group. The public npm
CLI, external TestFlight, Beta App Review, public App Store release, and the
separately controlled Apple-silicon automatic-update feed remain unchanged.

## Acceptance

1. Install the architecture-matched build 39 on an Apple-silicon or Intel Mac.
2. Confirm an interrupted prior app instance cannot leave a competing native
   server or cloud-host worker after build 39 opens.
3. Start a new Scratchpad thread and send a message without a shared-socket,
   WebSocket handshake, or `list_turns` compatibility error.
4. Open composer tools and confirm the model list and model-specific reasoning
   levels match the paired iPhone experience.
5. Choose a different model and reasoning level, reopen ClawDad, and confirm the
   selections persist.
6. Confirm the header uses the ClawDad wordmark and baby-crawfish mascot from the
   iPhone app.
7. Launch `codex` in Terminal and confirm the shared app server initializes.
