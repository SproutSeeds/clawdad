# ClawDad iPhone 0.7.0 Build 29

ClawDad iPhone build 29 makes the Remote Assist keyboard get out of the way
without sacrificing the remote click the user intended to send.

## What Was Wrong

The iPhone keyboard was backed by a hidden first-responder input view. A normal
tap on the remote viewport sent a click to the Mac but did not resign that
first responder, so the keyboard remained open and covered the lower-right
controls.

## Included

- Flushes pending keyboard text before dismissing the iPhone keyboard.
- Dismisses the keyboard on a normal one-finger viewport tap and forwards the
  same mapped click to the paired Mac.
- Keeps dragging, scrolling, pinching, right-clicking, and double-tap zoom on
  their existing interaction paths.
- Keeps the compact lower-right launcher above a docked software keyboard.
- Dismisses the keyboard before opening the controls so the compact panel fits
  in portrait and landscape.
