# ClawDad 0.7 Paid Beta 3

ClawDad 0.7 beta 3 is a privacy and certification maintenance release for the
founding paid beta. It uses the existing TestFlight iPhone build 19 with an
updated Mac app and runtime.

## Included

- Persists only the minimum verified StoreKit access state on the paired Mac.
- Keeps Apple-signed transaction proof and transaction identifiers out of the
  on-disk entitlement snapshot.
- Adds a privacy-safe release certification snapshot with mode-`0600` storage.
- Excludes project paths, device identifiers, credentials, messages, and
  customer project content from certification evidence.
- Enables the paired All/Project thread-scope check in the live-smoke scheme.
- Carries forward the signed installer, Sparkle update, per-device pairing,
  Direct and Queue delivery, voice, images, and Remote Assist experience from
  beta 2.

## Beta Gates

TestFlight build 19 must complete physical purchase, restore, cancellation,
fresh-pairing, reconnect, queue, long-turn, voice, image, cellular, and Remote
Assist checks. Restrictive-network Remote Assist certification requires a
Cloudflare TURN credential with Calls Write permission.

Apple still requires the account holder to confirm agreements, tax and banking,
the app privacy questionnaire, review contact, reviewer access, screenshots,
and the first-subscription attachment to app version 1.0.
