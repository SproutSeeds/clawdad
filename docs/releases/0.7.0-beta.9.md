# ClawDad 0.7 Paid Beta 9

ClawDad 0.7 beta 9 gives the paired iPhone and Terminal one shared Codex
thread writer on the Mac. Phone messages can join an open Codex CLI thread,
and the complete exchange remains in that saved thread when either client
reconnects.

## Included

- Runs one private local Codex app-server over a mode `0600` Unix socket.
- Opens ClawDad-launched Terminal sessions as clients of the shared writer.
- Sends Direct phone messages into a steerable active Terminal turn.
- Keeps Queue messages in ClawDad's durable FIFO and starts them with the full
  working directory, sandbox, model, reasoning effort, and attachment inputs
  after the thread becomes idle.
- Uses stable request IDs and atomic delivery claims to prevent duplicate sends
  across concurrent workers, connection loss, and worker crashes.
- Answers approvals only for turns created by the ClawDad client; Terminal-owned
  approvals remain with the Terminal client.
- Defers review, compaction, and other non-steerable states to a safe idle turn.
- Keeps Remote Assist, pairing, history, and diagnostics online if the Codex
  runtime is temporarily unavailable, then recovers it through the host health
  loop.
- Preserves an explicit isolated-mode rollback for Codex CLI compatibility.

## Distribution

- npm package: `clawdad-0.7.0-beta.9.tgz`
- Mac host CLI/service: `0.7.0-beta.9`
- Native Mac companion remains `0.7.0 (25)` because its UI and Remote Assist
  implementation are unchanged.
- iPhone companion remains private TestFlight build `0.7.0 (30)` because no
  mobile binary change is required.

## Acceptance

- Open a saved project thread in Terminal through the shared runtime.
- Send one Direct message to that thread from the paired iPhone and confirm the
  message and Codex response appear in Terminal.
- Close and reopen the Terminal client, resume the thread, and confirm the phone
  exchange remains in its history.
- Send a Queue message during an active turn and confirm it starts once that
  turn is idle.
- Confirm `clawdad codex-runtime status --json`, `clawdad prod-doctor --json`,
  Remote Assist, and normal phone history remain healthy.
