# ClawDad iPhone 0.7.0 Build 27

ClawDad iPhone build 27 keeps both Remote Assist control pages compact at the
lower-right corner of the remote desktop.

## Included

- Constrains the primary controls to 148 points before padding, for a 168-point
  complete panel.
- Constrains Special Commands to 196 points before padding, for a 216-point
  complete panel.
- Prevents SwiftUI's flexible grids from accepting the full viewport width and
  stretching the rounded panel background across the remote desktop.
- Preserves the 36-point lower-right launcher inside its 44-point touch target,
  the explicit Special Commands Back control, outside-tap dismissal, and the
  collapse-after-action behavior.
- Adds a source regression that binds each control page to its intended width.

## Distribution Boundary

Build 27 is limited to the private `ClawDad Internal` TestFlight group. The
external founding-customer group, Beta App Review, and public App Store
submission remain behind the existing physical-device and human gates.
