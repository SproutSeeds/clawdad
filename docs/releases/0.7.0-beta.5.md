# ClawDad 0.7 Paid Beta 5

ClawDad 0.7 beta 5 is a coordinated Mac and iPhone reliability release for
the founding paid beta. It pairs Mac app `0.7.0 (22)` with iPhone app
`0.7.0 (24)`.

## Included

- Adds a project-directory button to the iPhone project picker. A trusted
  phone can create one named project inside the Mac's configured primary
  projects root; the Mac validates the name, registers the project, wires its
  first Codex thread, and selects it on the phone.
- Adds on-demand Read Aloud controls for both sent messages and Codex
  responses. Speech generation starts on the paired Mac, and Settings offers
  an explicit Umbra fallback when Mac speech is unavailable.
- Keeps generated speech local to the trusted host path and transfers only the
  requested audio to the iPhone through signed, bounded chunks.
- Replaces ambiguous connection and Remote Assist loading states with clear
  relay, paired-Mac reconnect, host-offline, and 25-second timeout messages.
- Carries the canonical Mac-app instance guard and Remote Assist session-answer
  repairs that prevent duplicate host ownership and stale WebRTC answers.
- Preserves one active worker per Codex session: Direct steers the matching
  turn, while work for another busy session remains durably queued.
- Expands the private physical-certification ledger so project creation and
  each Mac-first/fallback Read Aloud path must be recorded independently.

## Beta Gates

Beta 5 is live through npm, the GitHub prerelease, the signed Mac update feed,
the installed Mac build, and the private internal TestFlight group. Fresh
iPhone installation, project creation, both Read Aloud buttons, Mac-only
speech, Umbra fallback, Wi-Fi-to-cellular recovery, Remote Assist, voice,
image, queue, and long-turn checks remain explicit device gates.

Founding-customer TestFlight distribution and public App Store submission stay
closed until those physical checks and the remaining Apple review details are
complete and explicitly approved.
