# ClawDad iPhone 0.7.0 Build 30

ClawDad iPhone build 30 adds a Remote Assist Command-T shortcut and a safe
composer Cut control. It pairs with ClawDad Mac beta 8, version `0.7.0 (25)`.

## Included

- Adds Command-T to Remote Assist Special Commands with a clear accessibility
  label for opening a new tab in the active Mac app.
- Adds a scissors control beside Copy in the iPhone composer.
- Copies the exact draft, including leading and trailing whitespace, before
  clearing the editor.
- Keeps the draft unchanged if the clipboard write fails.
- Returns focus to the empty editor after a successful cut so typing can
  continue immediately.
- Keeps the same Command-T shortcut and Cut behavior available in the Mac
  experience through the paired beta 8 host/runtime.

## Verification

- Run the Node, protocol, Mac, and iPhone Swift suites from the release source
  checkpoint.
- Build the generated iOS project and archive `0.7.0 (30)` with the production
  cloud endpoint, founder bypass disabled, and Apple Distribution signing.
- Upload the exact archive to App Store Connect and wait for `VALID` processing.

## Distribution Boundary

Build 30 is for the private `ClawDad Internal` TestFlight group. The external
founding-customer group, Beta App Review, public TestFlight link, and App Store
submission remain behind the existing physical-device and human gates.

## Physical Acceptance

- Install Mac beta 8 build 25 before installing iPhone build 30.
- Send Command-T from Remote Assist and confirm exactly one new tab opens in
  the active Mac app without a literal `t` or a held Command modifier.
- Cut a draft containing spaces and a line break; confirm the clipboard keeps
  the exact text, the composer clears, and the editor remains ready to type.
- Recheck Command-Tab, keyboard dismissal, pointer input, clipboard, reconnect,
  and locked-Mac behavior.
