# ClawDad 0.7 Native Beta 14

The Apple-silicon and Intel downloads contain the same Mac build 36 product
surface. This release makes Codex readiness precise: the setup assistant now
distinguishes a usable local sign-in from the separately verified current
Codex release. The matching private iPhone companion remains `0.7.0 (33)`.

## Included

- Reports the installed Codex version and ChatGPT sign-in state independently
  from the online update check.
- Checks OpenAI's official Codex release channel and compares semantic versions
  without treating installation alone as proof that Codex is current.
- Shows clear `Install`, `Sign in`, `Update available`, `Up to date`, and
  `Installed & signed in` states in the Mac setup assistant.
- Offers an explicit update button only after the customer chooses it. The
  action uses OpenAI's official standalone installer and preserves the shared
  `~/.codex` account and thread history.
- Keeps local setup usable when the release check is temporarily unavailable.
  ClawDad reports that currentness is unknown and never makes a false update
  claim.
- Caches successful release checks briefly and lets the customer choose
  **Check again** for a fresh result.
- Skips the network update check on controller-only Macs where local Codex is
  optional.
- Carries forward the bundled Node and ORP runtime, multi-computer routing,
  Mac-to-Mac pairing, multi-display Remote Assist, Terminal Tabs, Read Aloud,
  speech-to-text, image attachments, directory creation, clipboard controls,
  and special commands.

## Distribution Boundary

This native beta publishes the signed Mac installers through
`https://clawdad.earth/` and the public `v0.7.0-beta.14` GitHub release. iPhone
build 33 remains assigned only to the internal TestFlight group. The public npm
CLI, external TestFlight, Beta App Review, public App Store release, and the
separately controlled Apple-silicon automatic-update feed remain unchanged.

## First-Run Acceptance

1. Install the architecture-matched build 36 on an Apple-silicon or Intel Mac.
2. On a host Mac with an older Codex CLI, confirm the setup assistant shows the
   installed version, signed-in state, current release, and **Update available**.
3. Choose the update action, wait for completion, then choose **Check again**
   and confirm the row reports **Up to date**.
4. Disconnect networking temporarily and confirm an installed, authenticated
   Codex remains usable while the row says its update status is unavailable.
5. Choose controller-only and confirm setup completes without a local Codex
   install or release request.
6. Reopen ClawDad and confirm the selected project home, paired computers,
   threads, and Remote Assist capabilities remain intact.
