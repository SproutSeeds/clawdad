# ClawDad Mac 0.7.0 Build 29

ClawDad Mac build 29 makes the Terminal Automation permission handoff from
Remote Assist self-guiding.

## Included

- Opens the exact macOS Privacy & Security Automation pane when a Terminal Tabs
  catalog or focus request is denied Automation access.
- Brings System Settings forward on the paired Mac so the ClawDad-to-Terminal
  toggle is immediately available.
- Tells the iPhone that System Settings opened and directs the user to tap
  Refresh after enabling Terminal.
- Preserves the ordinary first-time macOS Allow or Don't Allow dialog and opens
  Settings only after macOS reports that Automation access was denied.
- Carries forward the Terminal tab switcher and display selector used by iPhone
  TestFlight build 32.

## Distribution Boundary

Build 29 is a private signed and notarized native Mac release. The iPhone stays
on private internal TestFlight build 32. The public npm package, git tags,
GitHub release assets, public Sparkle appcast, external TestFlight group, Beta
App Review, and App Store submission remain unchanged.

## Physical Acceptance

- Keep iPhone TestFlight build 32 installed.
- Open Remote Assist, expand `...`, and tap the Terminal icon.
- If the standard macOS consent dialog appears, choose Allow.
- If access is denied, confirm System Settings opens directly to Privacy &
  Security > Automation.
- Enable Terminal under ClawDad, return to the iPhone, and tap Refresh.
- Select a Terminal row and confirm its exact window and tab comes forward.
