# ClawDad 0.7 Native Beta 10

ClawDad native beta 10 consolidates the paired iPhone and Mac onto one bundled
Mac runtime and adds multi-display Remote Assist. The Mac companion is
`0.7.0 (26)` and the matching private iPhone companion is `0.7.0 (31)`.

## Included

- Runs paired-phone messaging, history, attachments, speech, directory creation,
  and Remote Assist through the runtime bundled inside the signed Mac app.
- Reuses one private local Codex app-server so Terminal and ClawDad can safely
  continue the same saved thread.
- Reads the native server token from a mode-restricted file instead of exposing
  it in process arguments.
- Lets the iPhone choose among connected Mac displays from the compact Remote
  Assist menu.
- Switches the existing video track transactionally, pauses remote input until
  the selected display is ready, and rolls back if capture cannot commit.
- Maps clicks against the selected display's real global bounds, including
  Retina scaling and displays arranged left of or above the primary display.
- Falls back to the primary available display when a selected screen disconnects.
- Adds CMD+T to Special Commands and Cut beside Copy in iPhone and Mac message
  composers.

## Distribution Boundary

This is a private native release: a signed and notarized Mac application plus
TestFlight build 31 in `ClawDad Internal`. The public npm package, public GitHub
release assets, public appcast, external TestFlight group, Beta App Review, and
App Store submission are outside this release.

  attachment, dictation, Read Aloud, and directory-creation behavior.
- Open Remote Assist with at least two connected Mac displays and switch both
  directions without opening a second session.
- Rearrange displays, select a screen with a negative global origin, and confirm
  click alignment.
- Disconnect the selected display and confirm the session falls back cleanly.
- Recheck CMD+T, Command-Tab, Control-C, Control-J, keyboard dismissal,
  clipboard, reconnect, Mac lock/unlock, and Wi-Fi-to-cellular transitions.
