# ClawDad 0.7 Paid Beta

ClawDad 0.7 brings the full Mac and iPhone companion experience into one
customer-ready beta.

## Included

- Continue the same Codex project threads from Mac or iPhone.
- Send Direct messages immediately or Queue them behind an active turn.
- Browse recent threads across every configured project or within one project.
- Attach images, dictate messages, copy prompts and responses, and hear replies.
- Open an authenticated, full-screen Remote Assist session when the Mac needs a
  visual click, terminal input, browser approval, or unlock.
- Pair an iPhone by QR code and reconnect automatically after launch.
- Check for signed ClawDad updates from the Mac app.
- Open support logs and copy a privacy-safe diagnostic report from Settings.

## Beta Notes

ClawDad requires Codex to be installed and signed in on the paired Mac. Remote
Assist requires Screen Recording and Accessibility access that the Mac owner
approves in System Settings.

This founding beta is intended for invited customers while subscription,
support, reliability, and App Store release gates receive final certification.
