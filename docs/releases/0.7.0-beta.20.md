# ClawDad 0.7 Native Beta 20

The Apple-silicon and Intel downloads contain the same Mac build 42 product
surface. The matching private iPhone companion is `0.7.0 (35)`. This release
adds unread-response notifications to the Remote Assist Terminal Tabs
switcher by mirroring Terminal's own background-tab alert.

## Included

- Reads Terminal's native `TabAlert` accessibility metadata for each window
  and tab without reading terminal contents, history, commands, or responses.
- Sends unread activity through a backward-compatible Remote Assist protocol;
  older Windows hosts continue to decode with unread activity set to false.
- Refreshes the Terminal Tabs catalog every two seconds only while that
  switcher is open.
- Shows a gold notification dot and `Response ready` on unread tab rows, plus
  an unread count in the switcher header and a badge on the Terminal launcher.
- Clears the notification through Terminal's normal behavior when the tab is
  focused.
- Announces unread response state and counts through VoiceOver.
- Carries forward multi-computer routing, Mac-to-Mac pairing, multi-display
  Remote Assist, Terminal Tabs, Read Aloud, speech-to-text, image attachments,
  directory creation, model/reasoning controls, and special commands.

## Distribution Boundary

This native beta publishes signed Mac installers through
`https://clawdad.earth/` and the public `v0.7.0-beta.20` GitHub release. iPhone
build 35 is assigned only to the internal TestFlight group. The public npm CLI,
external TestFlight, Beta App Review, public App Store release, and the
separately controlled automatic-update feeds remain unchanged.

## Acceptance

1. Install the architecture-matched Mac build 42 and confirm the embedded
   runtime reports `0.7.0-beta.20`.
2. Leave a Codex Terminal tab in the background until its native Terminal
   alert appears.
3. Open Remote Assist, open Terminal Tabs, and confirm that tab shows a gold
   dot and `Response ready` within two seconds.
4. Focus the indicated tab and confirm its unread notification clears.
5. Close Terminal Tabs and confirm background catalog polling stops.
