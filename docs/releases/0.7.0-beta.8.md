# ClawDad 0.7 Paid Beta 8

ClawDad 0.7 beta 8 hardens Remote Assist input and adds the paired-Mac support
for opening a new tab from the iPhone. The Mac companion is `0.7.0 (25)` and
pairs with the private iPhone `0.7.0 (30)` companion.

## Included

- Sends Command-Tab as a complete Command-down, Tab-down, Tab-up,
  Command-up sequence so Command cannot remain held after app switching.
- Uses a private macOS event source for Remote Assist keyboard, pointer, and
  scrolling input, keeping synthetic modifier state isolated from normal Mac
  input.
- Explicitly clears modifier flags on ordinary pointer and scroll events.
- Releases any remotely held key or mouse button when the session or control
  channel closes, using the last remote pointer position for safe drag cleanup.
- Surfaces a clear startup error if macOS cannot create the isolated input
  source instead of opening a partially controllable session.
- Dismisses the iPhone keyboard on a normal Remote Assist viewport tap while
  preserving the same click for the paired Mac.
- Keeps the compact controls launcher reachable above the software keyboard
  and dismisses the keyboard before expanding the controls.
- Adds Command-T to the typed Remote Assist shortcut allow-list and sends it as
  a balanced system Command-down, T-down, T-up, Command-up sequence.
- Adds a composer Cut control on iPhone and Mac that copies the exact draft,
  clears it only after clipboard success, and returns focus to the editor.

## Distribution Boundary

The iPhone build remains limited to `ClawDad Internal`. The external
founding-customer group, Beta App Review, and public App Store submission stay
behind the existing physical-device and human gates.

## Physical Acceptance

- Use Command-Tab from Remote Assist, return to Chrome, and confirm a YouTube
  video opens in the current tab with a normal tap.
- Confirm Terminal tabs remain individually clickable after Command-Tab.
- Close Remote Assist during a harmless drag and confirm the mouse button is
  released at the last remote pointer position.
- Recheck Control-C, Control-J, Escape, Tab, arrows, Control-L, pointer,
  scrolling, clipboard, keyboard, and reconnect behavior.
- Send Command-T from Special Commands and confirm exactly one new tab opens
  without a literal `t` or a held Command modifier.
- Cut one draft on iPhone and one on Mac; confirm the exact draft reaches the
  clipboard, the editor clears, and typing can resume immediately.
