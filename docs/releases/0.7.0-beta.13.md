# ClawDad 0.7 Native Beta 13

The Apple-silicon and Intel downloads contain the same Mac build 35 product
surface. This release completes the guided multi-computer setup and keeps the
native host responsive while customers authorize access to projects stored on
external drives. The matching private iPhone companion remains `0.7.0 (33)`.

## Included

- Bundles a checksum-verified Node 24 LTS executable and ORP runtime inside the
  signed app for each Mac architecture.
- Opens the local ClawDad control plane immediately while the shared Codex
  app-server starts in the background, keeping setup and diagnostics available
  when Codex is missing, signed out, or slow to initialize.
- Adds a four-step setup assistant for choosing this Mac's role, checking the
  managed runtime, installing the official standalone Codex CLI with explicit
  consent, signing in with ChatGPT, choosing the project home, and pairing
  devices.
- Opens the workspace picker before scanning saved projects, including project
  homes on removable drives, so macOS can associate the customer's selection
  with the signed ClawDad app.
- Keeps the managed Node services as direct children of the signed ClawDad app
  and defers queued background catalog work until setup is complete. This keeps
  removable-volume authorization attached to ClawDad and prevents the blank
  first-run window seen in build 34.
- Declares the microphone, removable-volume, Desktop, Documents, Downloads,
  Automation, Screen Recording, and Accessibility purposes used by the native
  experience.
- Installs Codex to `~/.local/bin` so the same executable is available from
  Terminal, while ClawDad and Terminal share `CODEX_HOME` at `~/.codex`.
- Supports controller-only Macs without requiring a local Codex sign-in.
- Keeps every paired iPhone computer profile scoped to its own project, Codex
  thread, model, reasoning setting, catalog, history, and Remote Assist host.
- Keys an opened iPhone thread by computer, project, and Codex session so a
  computer switch cannot leave a stale host's thread sheet active.
- Carries forward native Mac-to-Mac pairing, multi-display Remote Assist,
  Terminal Tabs, Read Aloud, speech-to-text, image attachments, mobile
  directory creation, clipboard controls, and special commands.

## Distribution Boundary

This native beta publishes the signed Mac installers through
`https://clawdad.earth/` and the public `v0.7.0-beta.13` GitHub release. iPhone
build 33 is distributed only to the internal TestFlight group. The public npm
CLI, external TestFlight, Beta App Review, and public App Store release remain
unchanged.

## First-Run Acceptance

1. Install the architecture-matched build 35 on a clean Apple-silicon or Intel
   Mac and confirm the setup assistant appears before any system Node or Codex
   dependency is required.
2. Choose controller-only and complete setup without Codex, or choose a host
   role, approve the official Codex install, sign in with ChatGPT, and select a
   project home, including an external volume when desired.
3. Confirm the main workspace renders immediately after setup, then close and
   reopen ClawDad and confirm the service becomes ready using the bundled Node
   runtime.
4. Pair the iPhone with two Macs, switch between them, and confirm each restores
   its own project and thread before sending a message.
5. Open Remote Assist to the selected Mac, change displays, click and type, use
   Terminal Tabs, and end the session.
6. Pair two Macs in each authorized direction and repeat the Remote Assist
   check from the desktop controller.
