# ClawDad Mac 162 · Reliable app account activation

Completed project requests now release account activation correctly. Project history's `answered` status is normalized to completed account work, including imported requests. Actual waits identify the ClawDad request; unresolved delivery receipts offer recovery instead of claiming work is finishing.

The active email and weekly allowance come from the running app server. Saved account previews remain separate. Native app work requires an explicitly activated profile from startup, and reuse verifies both its authentication home and subscription identity. Ordinary Terminal launches and sign-ins remain independent.

An expired source login can transition only after its exact process and account descriptor, idle conversations, settings, histories, drafts, empty queues and resolved receipts are captured. The destination always requires verified subscription access. Activation preserves conversations and never sends a model request.

This private native release contains the account activation changes. The separate uncommitted Assistant turn-control feature remains outside this build. No iPhone binary update is required for the corrected server state and recovery messages.
