# Mac 167 and iPhone 104: Shared subscription intelligence

The Assistant, structured research reviews, project summaries, delegate plans and run summaries now run through the computer's selected ChatGPT-authenticated Codex app server. Account verification happens before delivery, and saved request/turn receipts prevent replay after an uncertain response. Existing Assistant conversation IDs and histories are retained.

Agent access in Settings saves the computer's default file/command permissions, automatic safety review or Ask me, and native tool/computer-control preferences. Full computer access with automatic review is the initial default. New Assistant and manual requests inherit these settings; current work retains its captured permissions. The composer also offers Computer default, Repo scoped, and Full access.

The native tool bridge binds each call to the active user request in its exact thread. It carries ClawDad computer inspection/capture/control and Terminal tools into manual app-server conversations as well as the Assistant. Pending Assistant questions and permission decisions are available in Agent access settings. Research reviewers and summary helpers retain their evidence-only role; their work participates in account-switch admission and tracking.

The selected-account launcher now places Keychain settings in the correct Codex command scope, repairing the missing-bearer Assistant failure. API keys are removed from selected-account process environments; native execution verifies the selected ChatGPT subscription before model work.

Mac installation and the existing internal TestFlight group are the distribution destinations. Windows host verification remains pending while Umbra is unavailable; this release does not certify Windows native-control or Linux support.

Final installed checks also repaired manual dispatch and history lookup for transcripts stored in account-specific Codex homes, and corrected desktop Settings form nesting so saved controls load and remain usable.

Fresh conversations are validated against their exact live shared owner before Codex has written the first transcript. The browser-module graph is verified through HTTP so missing Settings imports cannot pass release tests.

Native tool configuration is verified before dispatch. Idle ClawDad inspection clients release their own subscriptions before configuration is reapplied to the same thread; account migration inspections do the same. Other live clients are preserved, and a configuration that did not take effect stops before the model message.
