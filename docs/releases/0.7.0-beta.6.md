# ClawDad 0.7 Paid Beta 6

ClawDad 0.7 beta 6 brings the Mac workspace experience up to parity with the
paired iPhone while keeping the desktop-only operating controls intact. The
candidate pairs Mac app `0.7.0 (23)` with the existing iPhone app
`0.7.0 (24)`.

## Included

- Replaces the compact Mac project dropdown with a searchable, grouped project
  picker that shows project names, paths, selection state, and an Add Existing
  action.
- Makes the project-row plus button a direct New Project Directory action. New
  directories default to the Mac's configured primary projects root, use the
  same name boundary as the paired iPhone and server, and keep creation status
  visible until the Mac finishes.
- Adds a dedicated plus button for starting a new Codex session while retaining
  the existing session dropdown and thread, rename, import, terminal, and
  delegation controls.
- Adds a persistent Threads panel with Project and All scopes. Project shows
  the selected directory's threads; All shows the 20 most recent Codex threads
  across configured projects. Thread cards open the existing conversation view
  with copy and on-demand Read Aloud controls.
- Persists the chosen thread scope locally, caches recent thread summaries for
  fast startup, and restores focus when project, creation, and conversation
  overlays close.
- Unifies Escape behavior around one back-one-step path so the topmost terminal,
  confirmation, project, conversation, settings, or composer surface closes
  predictably.
- Expands the desktop content width and responsive rules so thread cards use two
  columns when space allows and collapse cleanly on narrow windows.

## Unchanged Companion Build

The iPhone remains on build 24. Its project creation, Mac-first Read Aloud,
voice transcription, image delivery, reconnect handling, and Remote Assist
features are unchanged in this release.

## Candidate Artifacts

- npm package: `clawdad-0.7.0-beta.6.tgz`
- Mac update: `ClawDad-0.7.0-beta.6-mac.zip`
- Mac installer: `ClawDad-0.7.0-beta.6-mac.dmg`

## Verification Boundary

Automated Node and Swift checks, signed package validation, notarization,
Gatekeeper assessment, installed-version checks, and local Mac UI inspection
belong to this release pass. Fresh iPhone-to-Mac validation remains a physical
device gate and does not require a new TestFlight upload.
