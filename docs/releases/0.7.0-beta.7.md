# ClawDad 0.7 Paid Beta 7

ClawDad 0.7 beta 7 adds the paired-Mac half of iPhone Remote Assist special
commands. The candidate pairs Mac app `0.7.0 (24)` with iPhone app
`0.7.0 (26)` so every visible shortcut has a matching signed protocol handler.

## Included

- Extends the Remote Assist input protocol with an enumerated shortcut
  allow-list for Control-C, Control-J, Escape, Tab, four arrow keys, Control-L,
  and Command-Tab.
- Sends Control and navigation commands only to the focused editable Mac app.
- Routes Command-Tab through the macOS system event stream so it can switch
  applications while keeping it as the sole system-wide command.
- Rejects all special commands while the Mac is locked and retains the
  existing Accessibility permission boundary.
- Matches iPhone build 26's smaller lower-right launcher, nested Special
  Commands panel, explicit back control, and one-launcher collapse behavior.

## Candidate Artifacts

- npm package: `clawdad-0.7.0-beta.7.tgz`
- Mac update: `ClawDad-0.7.0-beta.7-mac.zip`
- Mac installer: `ClawDad-0.7.0-beta.7-mac.dmg`
- iPhone companion: private TestFlight build `0.7.0 (26)`

## Distribution Boundary

The iPhone build remains limited to `ClawDad Internal`. The external
founding-customer group, Beta App Review, and public App Store submission stay
behind the existing physical-device and human gates.

## Physical Acceptance

- Confirm the compact launcher and nested menu in portrait and both landscape
  orientations.
- Confirm Control-C, Control-J, Escape, Tab, all four arrows, and Control-L in
  a harmless focused terminal or Codex CLI session.
- Confirm Command-Tab switches the active Mac application.
- Confirm every command collapses the overlay and locked-screen attempts stay
  unavailable.
