# ClawDad 0.7 Native Beta 18

The Apple-silicon and Intel downloads contain the same Mac build 40 product
surface. This release makes preserved local state recover cleanly after an app
upgrade: stale active Codex thread bindings are replaced with fresh local
threads, and expired ChatGPT credentials open a guided Sign In Again flow. The
matching private iPhone companion remains `0.7.0 (33)`.

## Included

- Validates the selected active Codex thread binding when a message is sent.
- Quarantines only the selected active binding when its transcript is
  definitively missing, mismatched, tied to another project folder, or from an
  unsupported Codex source.
- Preserves inactive historical thread records for later review or manual
  repair.
- Creates a fresh local thread with the same title and records a durable alias
  from the stale thread ID to the replacement.
- Transparently routes the pending message to the replacement thread when an
  older Mac or iPhone view submits the stale ID.
- Returns structured recovery metadata so the Mac composer can switch to the
  replacement thread without losing the draft or requiring a manual
  `sessions-doctor` command.
- Recognizes the Codex refresh-token reuse and access-token refresh failure
  messages as authentication recovery events.
- Opens System Readiness directly on the Codex step and launches a fresh
  ChatGPT sign-in flow on the affected Mac.
- Stops the shared Codex app-server, clears the expired local login, invokes
  the official `codex login` browser flow, verifies `codex login status`, and
  restarts the shared app-server after a successful sign-in.
- Polls the local sign-in result and reports Ready, Signing in, or Sign In
  Again without reading or displaying credentials.
- Gives paired phones an accurate host-side instruction when the recovery must
  be completed on the Mac.
- Carries forward the live model and reasoning catalog, iPhone-parity branding,
  bundled Node and ORP runtime, multi-computer routing, Mac-to-Mac pairing,
  multi-display Remote Assist, Terminal Tabs, Read Aloud, speech-to-text, image
  attachments, directory creation, clipboard controls, and special commands.

## Distribution Boundary

This native beta publishes signed Mac installers through
`https://clawdad.earth/` and the public `v0.7.0-beta.18` GitHub release. iPhone
build 33 remains assigned only to the internal TestFlight group. The public npm
CLI, external TestFlight, Beta App Review, public App Store release, and the
separately controlled Apple-silicon automatic-update feed remain unchanged.

## Acceptance

1. Install the architecture-matched build 40 over an existing ClawDad install
   with preserved Application Support and `~/.codex` data.
2. Send through an active thread ID with no matching transcript and confirm it
   is quarantined while a fresh local thread becomes active.
3. Submit again from an older view that still holds the stale ID and confirm ClawDad
   routes the message to the fresh thread.
4. Simulate a failed Codex refresh token and confirm System Readiness opens on
   the Codex step with Sign In Again.
5. Complete the browser login and confirm ClawDad reports Codex ready and the
   shared app-server accepts a new message.
6. Confirm healthy active and inactive historical threads remain unchanged.
