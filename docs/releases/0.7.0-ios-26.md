# ClawDad iPhone 0.7.0 Build 26

ClawDad iPhone build 26 tightens the Remote Assist launcher and adds a bounded
special-command surface for the matching Mac `0.7.0 (24)` companion.

## Included

- Shrinks the visible Remote Assist launcher from 52 to 36 points while
  retaining a 44-point touch target.
- Anchors the launcher four points from the full-screen viewport's lower-right
  bounds, including outside the ordinary safe-area padding.
- Adds a Special Commands icon to the existing controls panel and an explicit
  back control inside the same compact overlay.
- Adds individual keycaps for Control-C, Control-J, Escape, Tab, four arrow
  keys, Control-L, and Command-Tab.
- Collapses the complete overlay back to the single launcher after every
  command and disables special commands while the Mac is locked.
- Extends the signed Remote Assist input protocol with an enumerated shortcut
  allow-list. Targeted commands go only to the focused Mac app; Command-Tab is
  the sole system-wide command.

## Distribution Boundary

Build 26 is limited to the private `ClawDad Internal` TestFlight group. The
external founding-customer group, Beta App Review, and public App Store
submission remain behind the existing physical-device and human gates.

## Physical Acceptance

- Confirm the small launcher is fully visible and comfortably tappable in
  portrait and both landscape orientations.
- Confirm the back keycap returns from Special Commands to the main controls,
  outside taps close the overlay, and every action returns to one launcher.
- Confirm Control-C interrupts a harmless running command and Control-J has the
  intended behavior in the Codex CLI.
- Confirm Escape, Tab, all arrows, Control-L, and Command-Tab behave correctly
  on the paired Mac.
