# ClawDad 0.7 Paid Beta 4

ClawDad 0.7 beta 4 is a security and session-health maintenance release for
the founding paid beta. It uses the existing TestFlight iPhone build 19 with
Mac app build 19 and an updated bundled runtime.

## Included

- Redacts authorization values, credential flags, sensitive environment
  assignments, URL credentials, and recognized token formats before Codex
  command events are persisted.
- Applies the same credential redaction to live delegate checkpoints.
- Keeps healthy long-running and approval-waiting Codex turns active during
  session-doctor audits.
- Repairs stale local placeholder sessions by selecting the real provider
  session represented by the current mailbox.
- Carries forward the privacy-safe entitlement and certification snapshots,
  signed installer and Sparkle updates, per-device pairing, Direct and Queue
  delivery, voice, images, and Remote Assist experience from beta 3.

## Install

```sh
npm install -g clawdad@beta
```

The signed and notarized Mac ZIP and DMG are attached to this release.

## Beta Gates

TestFlight build 19 must complete physical purchase, restore, cancellation,
fresh-pairing, reconnect, queue, long-turn, voice, image, cellular, and Remote
Assist checks. Cloudflare Realtime/TURN is active with production credential
issuance, account analytics, Worker-enforced customer and global limits, and an
account-wide `$5` budget alert. Restrictive-network certification still
requires a forced-TURN physical TestFlight pass.

Apple still requires the account holder to confirm agreements, tax and banking,
the app privacy questionnaire, review contact, reviewer access, and the
first-subscription attachment to app version 1.0. The App Store draft already
contains the accepted 6.9-inch screenshot set.
