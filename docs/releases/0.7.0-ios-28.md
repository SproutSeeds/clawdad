# ClawDad iPhone 0.7.0 Build 28

ClawDad iPhone build 28 restores Read Aloud playback for sent messages and
Codex responses while preserving the compact Remote Assist controls from build
27.

## What Was Wrong

The paired Mac successfully generated and returned valid PCM WAV audio. The
iPhone then asked `AVAudioSession` for the `.playback` category with explicit
AirPlay and Bluetooth A2DP options. Those options are incompatible with that
category and caused the session setup to fail with OSStatus `-50` before the
audio player started.

## Included

- Activates `.playback` with `.spokenAudio` before playing prepared speech.
- Lets iOS manage the playback category's normal speaker, headphone, Bluetooth,
  and AirPlay routes.
- Keeps speech generation on demand after either a sent-message or
  Codex-response speaker control is tapped.
- Adds a regression that rejects explicit AirPlay and Bluetooth options in the
  playback-session setup.
- Retains build 27's compact lower-right Remote Assist controls and Special
  Commands.
