# ClawDad Mac 0.7.0 Build 33

ClawDad Mac build 33 adds the signed controller role required for private
Mac-to-Mac pairing and Remote Assist.

## Included

- A dedicated Mac controller identity and Keychain-scoped relay credentials.
- A Remote Computers section in desktop Settings for pairing, opening, and
  forgetting another Mac.
- A native Remote Assist window protected by Touch ID or the Mac login
  password.
- Multi-display selection, pointer and keyboard control, local-to-remote paste,
  remote-to-local copy, Command-Tab, Command-T, Control-C, Control-J,
  Control-L, Escape, Tab, and arrow commands.
- Existing Mac host, paired iPhone, Terminal Tabs, updater, and local runtime
  capabilities remain available in the same application.
- Apple-silicon release frameworks are thinned to arm64 before signing, keeping
  the notarized installer below the clawdad.earth single-file delivery limit.

## Pairing Direction

Each pairing grants one controller access to one host. Repeat the pairing flow
with a fresh code in the other direction to make control mutual. Revoking or
forgetting one saved computer does not silently grant access in the other
direction.

## Distribution

The build is Developer ID signed, notarized, stapled, and distributed as the
Mac download on `https://clawdad.earth/`. The npm package and iPhone TestFlight
build are separate release surfaces and are unchanged by this Mac build.
