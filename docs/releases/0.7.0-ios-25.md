# ClawDad iPhone 0.7.0 Build 25

ClawDad iPhone build 25 is a focused Remote Assist viewport update for the
existing Mac `0.7.0 (23)` companion.

## Included

- Removes the persistent Remote Assist title/status pill from the remote
  desktop viewport.
- Replaces the permanent top and bottom control rows with one compact floating
  controls button in the lower-right safe area.
- Opens Exit, Enter, paste, copy, keyboard, secure-session status, and the
  conditional zoom-reset action together in a one-tap menu.
- Collapses the menu after every action, when the connection leaves the active
  state, when the view closes, or when the user taps outside it.
- Keeps 48-point action targets, explicit VoiceOver labels, and visible
  back/exit behavior inside the menu.

## Distribution Boundary

Build 25 is for the private `ClawDad Internal` TestFlight group. The external
founding-customer group, Beta App Review, and public App Store submission stay
behind the existing physical-device and human approval gates.
