# ClawDad 0.7 Native Beta 11

The signed Mac release is available as separate Apple silicon and Intel
downloads. Both packages contain the same build 33 product surface and embedded
runtime.

ClawDad native beta 11 lets one Mac pair with and control another Mac through
the same private relay and Remote Assist model already used by the iPhone
companion. The Mac companion is `0.7.0 (33)`. The matching private iPhone
companion remains `0.7.0 (32)`.

## Included

- Adds a separate signed controller identity to every Mac installation, stored
  in macOS Keychain independently from that Mac's host identity.
- Adds **Remote Computers** to desktop Settings, where a short-lived pairing
  code copied from another Mac can be paired, opened, or forgotten.
- Verifies every paired host against the public key pinned in its pairing code
  before accepting pairing or Remote Assist messages.
- Stores each remote computer's relay credential in Keychain and keeps secrets
  out of the saved computer list and diagnostics.
- Adds a native Mac Remote Assist window with Touch ID or Mac-login
  authentication, multi-display selection, pointer and keyboard input,
  clipboard controls, and special commands.
- Keeps both directions explicit: pair Mac A to Mac B, then repeat with a fresh
  code in the opposite direction when Mac B should also control Mac A.
- Carries forward Terminal Tabs, multi-display iPhone Remote Assist, Read
  Aloud, speech-to-text, image attachments, mobile directory creation, and
  shared CLI thread continuity.
- Publishes the signed and notarized Mac installer as the direct Mac download
  on `https://clawdad.earth/`.

## Distribution Boundary

This is a native Mac release with a website-hosted signed installer. The iPhone
stays on private internal TestFlight build 32. The public npm package, external
TestFlight group, Beta App Review, and App Store submission are unchanged.

## Pair Two Macs

1. Install build 33 on both Macs and leave ClawDad open on each computer.
2. On the Mac to be controlled, open Settings, choose **Allow a Device**, and
   copy the current short-lived pairing code.
3. On the controlling Mac, open Settings, paste that code under **Remote
   Computers**, and choose **Pair Computer**.
4. Choose **Open Remote Assist** beside the saved Mac and approve Touch ID or
   the Mac login password.
5. Repeat steps 2-4 in the opposite direction if either Mac should be able to
   control the other.

## Physical Acceptance

- Pair a Mac laptop to a Mac Studio and open the Studio from the laptop.
- Switch displays, click and type, copy and paste in both directions, and send
  Command-Tab and Command-T.
- Close Remote Assist and confirm screen video stops.
- Repeat pairing in the opposite direction and open the laptop from the Studio.
- Pair the iPhone with both Macs and confirm each remains independently
  selectable as a Remote Assist host.
