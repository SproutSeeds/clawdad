# ClawDad Mac 0.7.0 Build 28

ClawDad Mac build 28 adds the private host support for choosing a Terminal tab
from Remote Assist on the paired iPhone.

## Included

- Returns a bounded list of open Terminal windows and tabs only when the paired
  iPhone requests it.
- Uses opaque tab identifiers and sends the tab title, window/tab position,
  selected state, and busy state. Terminal contents, history, commands, and
  process lists are excluded.
- Revalidates the requested tab and catalog revision before focusing it, then
  confirms the selected tab back to the iPhone.
- Keeps Terminal closed when it is not already running.
- Adds the macOS Automation permission description needed for user-approved
  Terminal control.
- Carries forward the Remote Assist display-catalog reliability repair from
  Mac build 27.

## Distribution Boundary

Build 28 is a private signed and notarized native Mac release. The public npm
package, git tags, GitHub release assets, and public Sparkle appcast remain
unchanged.

## Physical Acceptance

- Install the paired iPhone TestFlight build 32.
- Open Remote Assist, expand `...`, and tap the Terminal icon.
- Approve ClawDad's Terminal Automation request on the Mac if macOS asks.
- Choose a different Terminal row and confirm its window/tab comes to the front.
- Use Back and Refresh, then confirm the existing Screens control still works.
