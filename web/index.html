Remote Assist
Open this Mac from ClawDad on iPhone
1.
Allow Screen Recording

Click Screen Recording below. In System Settings, open Privacy & Security > Screen & System Audio Recording, then turn on ClawDad. Relaunch ClawDad if macOS asks.

2.
Allow Control Access

Click Control Access below. In System Settings, open Privacy & Security > Accessibility, then turn on ClawDad. The description "Allow assistive applications to control the computer" is the correct setting. Approve Touch ID or your password if prompted.

Remote Assist is ready when the toggle is on and both permission buttons say Allowed. Then tap the desktop icon in ClawDad on iPhone.
